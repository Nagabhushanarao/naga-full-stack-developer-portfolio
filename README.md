## 🚀 Local Development Setup

### Prerequisites
* **Node.js** (v18.0 or higher)
* **npm** (v9.0 or higher)

### 1. Clone the repository
```bash
git clone https://github.com/Nagabhushanarao/naga-full-stack-developer-portfolio.git
cd naga-full-stack-developer-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🚢 GitHub Pages Deployment

The repository includes a GitHub Actions workflow (`.github/workflows/deploy.yml`).

### To publish your portfolio live:
1. Commit and push the code to `main`:
   ```bash
   git add .
   git commit -m "feat: complete full stack developer portfolio with verified resume skills"
   git push origin main
   ```
2. Enable GitHub Pages in your GitHub repository:
   * Go to **Settings** → **Pages** on your repository.
   * Under **Build and deployment > Source**, select **GitHub Actions**.
3. Once the workflow completes, your site will be live at:
   **`https://nagabhushanarao.github.io/naga-full-stack-developer-portfolio/`**
